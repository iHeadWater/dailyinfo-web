# AI Daily Digest - 2026-10-14

## [AINews] Meta Muse Wonder &amp; Wonder Full: MSL’s Claude 5.5-tier Frontier Model

## 🧠 模型进展
- Meta Superintelligence Labs 发布 Muse Wonder 与 Muse Wonder Full，定位前沿个人/专业 agentic 模型，Wonder Full 在多项独立评测中接近或进入前沿。
- Artificial Analysis 评测显示 Wonder Full(max) 的 Intelligence Index 为 56、Wonder 为 52，均高于 Muse Spark 1.3 的 48，但 Opus 5.5 以 58 领先，且 Wonder Full 在 Terminal-Bench、GDPval、AA-Briefcase 等 agentic 基准显著提升。
- Vals AI 评测显示 Wonder Full Max 位列 Vals Index 第 5、ProofBench 达 94/100，Terminal-Bench 4 翻倍以上，Wonder 位列第 10。
- Muse Wonder 支持 1M 上下文和文本/图像/视频/音频输入、仅文本输出，定价为 $4 输入/$0.20 缓存输入/$20 输出每百万 tokens，Wonder Full 仅限 Muse Code 订阅者使用。
- 其他模型与训练进展包括 QwenGyre 弹性 RL 框架提升超长程 agent 训练，Decision 3.0 发布 0.6B–27B 开放多模态决策模型，GLM-Legal 成为 Harvey LAB/LegalBench 最强开源权重模型。

## 🤖 Agent/产品进展
- Muse Wonder 将驱动 Meta 的 Muse 个人 agent 产品，Wonder Full 支撑 Muse Code，且 Muse Code 可通过 curl 安装。
- QwenGyre 面向超长程 agent 的弹性 RL 训练，在 NL2RepoBench 上从 52.5% 提升到 58.5%，并减少约 44% 训练时间。
- Sakana MASS 让单个 27B 模型自组织多 agent 工作流并基于最佳团队轨迹微调，研究基准每输出 token 分数提升 1.2–1.6 倍。
- Claude Code 新插件 claude-show-your-work 可在终端显示截图、内嵌视频和 QA 记录，CraftAI 则让 Claude 在 Minecraft 中按自然语言建造。
- 消费级 agent 开始执行真实购物结账，ChatGPT 等助手可完成 Amazon 下单，但引发授权、会话持久化和误购安全担忧。
