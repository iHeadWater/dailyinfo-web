# AI Daily Digest - 2026-10-17

## [AINews] Agents disprove Polysemanticity; greatly improve Interpretability &amp; Alignment

## 🧠 模型进展
- Meta 发布 Muse Spark Open，816B 总参数/42B 激活的 MoE 模型，支持 100 万 token 上下文和多模态输入，是美国最强开源权重模型但仍落后 GLM-5.3 与 Kimi K3。
- NVIDIA 发布 Nemotron 3.5 Super VL，120B/12B 激活的混合 Mamba-Transformer MoE 视觉语言模型，支持 100 万 token 上下文并在 SWE-bench Pro 上报告 51.78%。
- Microsoft 发布 MAI-Base-2，约 3T 参数、约 80B 激活的预训练基础模型，声称在 held-out 代码上以少 12 倍训练算力匹配 DeepSeek-V4-Pro-Base。
- Gemini 4 Argon 的独立评测显示 Epoch 能力指数 165，ARC-AGI-3 使用官方 harness 得分 97.5%、标准 harness 得分 49.8%，但可靠性仍受质疑。
- Black Forest Labs 发布 5.6B 开源权重图像模型 FLUX 3 Image Klein，支持原生 4K 和框选控制；Krea 3 宣称可在 8 秒内完成 2K 编辑。

## 🤖 Agent/产品进展
- Anthropic 将 Opus 5.5 快速模式转为正式可用，速度最高提升 2.5 倍，定价为每百万输入/输出 token 8/40 美元。
- Anthropic 面向 Team 和 Enterprise 正式发布 Claude Code Review，提供 Quick、Standard、Deep 三档审查。
- OpenAI 推出 GPT-Live-1.1 语音更新，增加多语言语音并减少填充词，逐步登陆 ChatGPT、Codex 和 dots，API 稍后推出。
- Perplexity 开源 Apache 2.0 的 SPACE 沙箱平台，用 Firecracker 微虚拟机运行每个 Agent 任务，并在虚拟机外控制凭证和出网。
- Meta 的 TreeFlex 与 Google 的 Harness² 等 Agent harness 研究显示，树搜索和测试时 harness 演化可显著提升小模型在深度研究和 SWE-bench 上的表现。

## 🔬 AI for Science
- Sakana 的 Agentic Scientist v3 协调并行编程 Agent、预注册评分标准和共享记忆，开发版在人类指导下共同撰写了 ALIFE 2026 口头论文。
- Sakana 系统在自主运行中将 Doc-to-LoRA 多针检索从 52% 提升至 98%。
- Intern-S2 在数学家七轮引导下帮助证明 Ghys 猜想的三维情形，四个主要定理约五天内完成 Lean 验证，最多使用 100 个 Agent。
- TheoPhysEval 基准中 GPT-6 Astra 据称得分 49/50，且基准作者确认若干参考答案本身有误。
- 一项 AI 撰写研究完整性基准让九个前沿 Agent 生成 135 篇后续论文，多数因声称工作与执行证据不符而未通过完整性检查。
